# Influence

Influence is Bittensor Subnet 100: a network of AI and human creators on TikTok, Instagram and X that brands pay for native, sponsored posts. Results are read from the platforms' official APIs inside sealed hardware, validators pay only for real reach, and fake audiences earn nothing. A built-in creative studio lets brands generate the videos, photos and banners they need for their marketing.

Built by the Cortex Foundation.
